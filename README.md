# 數學跑跑樂園（南一版 三上）

四德學輔班學習樂園的三年級數學。學生回家用來「玩著複習」，每個單元只練最常錯的重點。

網址：https://snoopyteacher888.github.io/nani-math-3/

## 玩法
- 小橘往前跑，前面三扇門各寫一個答案。按下面的答案按鈕（或點跑道）換到那條路，跑進正確的門就得分。
- 選好後**再按一次**同一個按鈕可以衝刺，越早衝刺分數越多。
- 每局 10 題，5 顆愛心。答錯會扣愛心、看提示和解題過程，這題等一下會再出現一次。
- 星星：錯 0～1 題 3 顆、錯 2～3 題 2 顆、其他 1 顆。紀錄只存在這台裝置的瀏覽器。
- 速度：🐢 慢慢跑（時間 ×1.6）、🐇 一般、🐆 挑戰（×0.6）。
- 每題都可以按 🔊 念出來；地圖上可以開「自動念題目」。

## 目前的關卡
| 關卡 | 練什麼 | 錯誤選項設計 |
|---|---|---|
| 1-1 數字讀寫 | 國字↔數字、幾個千幾個十（中間有 0） | 三千零五 → 305、30005、3050 |
| 1-2 數線大挑戰 | 1 小格是多少、箭頭指哪裡 | 把 1 格當 1、差一格 |
| 2-1 加法進位 | 四位數加法（至少 2 次進位） | 沒進位、漏加某一次進位 |
| 2-2 減法退位 | 四位數減法、被減數中間有 0 | 大減小、借了沒減 1 |
| 3-1 乘法進位 | 二、三位數 × 一位數 | 漏加進位 |
| 3-2 乘法應用題 | 買東西、算總數；105×4 這類 | 用加的（a＋b）、漏加進位 |

應用題不顯示直式，讓孩子自己判斷要用哪一種算法。

## 檔案
- `index.html`、`style.css`：畫面
- `js/questions.js`：出題（每關一個 `gen()`，關卡清單在最下面的 `UNITS`）
- `js/game.js`：跑酷遊戲
- `tests/questions.test.js`：出題測試，執行 `node tests/questions.test.js`

## 新增單元
在 `js/questions.js` 寫一個 `genXxx()`，回傳 `{ text, say, answer, options, hint, explain }`，
再把它加到 `UNITS` 裡那個單元的 `stages`。
