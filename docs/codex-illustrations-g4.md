# 給 Codex 的插圖指令：四年級數學（翰林版四上）

> Codex：請直接照下面「指令開始」到「指令結束」的內容執行。

===== 指令開始 =====

請幫四年級數學複習遊戲畫「關卡插圖」，一共 **19 張**。畫風要和 `art/cards/` 裡已經畫好的三、五、六年級插圖**完全一致**（請先打開幾張來看，例如 `art/cards/g3-1-1.png`、`art/cards/g5-7-2.png`、`art/cards/g6-3-2.png`）。班上有不識字的學生，所以**圖本身要能看懂這關在練什麼**。

## 共同畫風（每一張都要一致）

- 手繪繪本風：彩色鉛筆／蠟筆質感，線條柔和，有一點手繪的不完美感。不要 3D、不要寫實照片、不要扁平向量 icon、不要 emoji 風。
- 色調溫暖、低彩度，主色：
  - 橘 `#E07A2E`
  - 藍 `#2A63A8`
  - 綠 `#2D8A57`
  - 紅 `#D9483B`
  - 米白 `#F8F6F0`
  - 深灰線條 `#2B2A28`
- 主角「小橘」：一隻圓滾滾的橘色小狐狸，頭上綁藍色頭帶，表情開心，長相和舊圖一樣。不必每張都有。
- **圖裡不要放任何中文字**（網頁會自己顯示標題），但可以有阿拉伯數字和符號，例如 `3050`、`×`、`5/5`、`90°`、`0.58`。
- **數學一定要正確**：畫出來的算式、角度、分數都要對（除了「找出乘法的錯」那張是故意畫錯的）。
- 構圖簡單，主體置中，留一圈空白，縮到很小（約 64×64）也看得出是什麼。每張只畫一個重點。

## 檔案規格

- 正方形 **512×512**，**透明背景 PNG**。
- **只存到 `art/cards/`**，檔名照下表（全小寫英數）。**不要**放進 `images/cards/`（網站用的小圖我會另外轉）。
- 「九九乘法大冒險」已經有 `nine.png`，不用再畫。
