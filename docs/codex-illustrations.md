# 給 Codex 的插圖指令（數學學習樂園關卡插圖）

> Codex：請直接照下面「指令開始」到「指令結束」的內容執行。

===== 指令開始 =====

請幫我畫一套兒童數學複習遊戲的「關卡插圖」，並存成圖檔。使用者是國小三、五、六年級的學生，其中有不識字的孩子，所以**圖本身要能看懂這關在練什麼**。

## 共同畫風（每一張都要一致）

- 手繪繪本風：彩色鉛筆／蠟筆質感，線條柔和，有一點手繪的不完美感。不要 3D、不要寫實照片、不要扁平向量 icon、不要 emoji 風。
- 色調溫暖、低彩度，主色：
  - 橘 `#E07A2E`
  - 藍 `#2A63A8`
  - 綠 `#2D8A57`
  - 紅 `#D9483B`
  - 米白 `#F8F6F0`
  - 深灰線條 `#2B2A28`
- 主角「小橘」：一隻圓滾滾的橘色小狐狸，頭上綁藍色頭帶，表情開心。可以在插圖裡出現（例如拿尺、倒水、切披薩），不必每張都有。
- 「九九乘法大冒險」的大魔王：可愛但有點調皮的紫色小怪獸，不可怕。
- 數線關卡的青蛙：可愛的綠色小青蛙，手繪風。
- **圖裡不要放任何中文字或標題文字**（網頁會自己顯示標題），但可以有簡單的阿拉伯數字或符號，例如 `0 5 10`、`+`、`×`、`1/4`、`90°`。
- 構圖簡單，主體置中，留一圈空白，縮到很小（約 64×64）也看得出是什麼。
- 每張只畫一個重點，不要塞滿。

## 檔案規格

- 正方形 **512×512**，**透明背景 PNG**。
- 存到 `images/cards/`，檔名照下表（全小寫英數）。
- 「九九乘法大冒險」三個年級共用一張 `nine.png`。
